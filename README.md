# Ldash

Ldash v1.0 is published by Laden AS.

## Linux

Download `Ldash-1.0-Linux.tar.gz` from the [v1.0 release](https://github.com/kim-laden/laden-dash/releases/tag/v1.0). Unpack it and run:

```bash
sh linux/install.sh
```

The installer needs Python 3, GTK 4, WebKitGTK 6, and the Python D-Bus bindings. It adds a Laden Ops menu entry and an `ldash` command for the current user.

Windows, Mac, and Android installers are on [laden.no](https://laden.no/en/portfolio/dash/).
